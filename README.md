## Getting started

Prerequisites
- Java JDK 11 or newer
- Gradle (or use the included Gradle wrapper if present)
- Kotlin (included via Gradle for most projects)

Build

If the project includes a Gradle wrapper, run:

```
./gradlew build
```

Or with Gradle installed:

```
gradle build
```

Run tests

```
./gradlew test
```

Open in IDE

If this is an Android project, open the repository in Android Studio. For other Kotlin/JVM projects, open in IntelliJ IDEA.
